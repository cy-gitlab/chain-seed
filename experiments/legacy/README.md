# Historical SeedEmu blockchain experiments

These archived sources include unfinished examples and an earlier Layer 2
prototype. They are development references and are not part of the supported
example suite.

Canonical examples live under `examples/`; reusable service implementations
live under `chainseed/`. New work should use these public interfaces.

Some prototypes require custom client binaries or other assets that are not
included. Check each example's requirements before running it.
